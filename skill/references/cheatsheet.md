# 决策规则速查 — 运去哪操作知识库物流专家

| 能力 | 一句话规则 |
|---|---|
| 商品建档与 SKU 对齐 | 先核 ERP SKU、实物识别码和平台 SellerSKU 的映射与审核状态，再进入入库或推单。 |
| 入库计划与装箱核对 | 核实仓、SKU、箱明细与标签后提交入库计划，按审核和上架状态逐步确认。 |
| 送仓预约与拖车交接 | 先判运输与送仓方式，再核单据状态、预约、询价确认、BOL、提货和 POD。 |
| 库存数量与报表核对 | 用时点快照找历史量、变动明细找差额，再按仓/SKU/库存类型核当前可用量。 |
| 订单异常与拦截分诊 | 先读错误码和订单/仓库状态，再在取消、拦截、召回或补发路径间分流并核结果。 |
| 店铺与 ERP 导单链路核对 | 确认唯一订单来源、授权、仓/SKU/物流映射，并用测试单核两侧状态与附件。 |
| 择仓审单拆单与调拨 | 先判 B2C 一件代发还是 B2B 调拨，再核择仓、审单、不拆条件和调拨目的地。 |
| 快递与卡车方案条件式比较 | 收集目的地、仓、尺寸重量、托盘和服务需求后，逐项核实时可用渠道与报价。 |
| 尾程轨迹与异动追踪 | 核面单来源与最新轨迹，选召回、更址或断更等异动项，再跟进工单状态。 |
| 退货计划与入库认领 | 先核退货计划和面单，再核仓库扫描、认领及处理意见，不凭物流妥投判断上架。 |
| 索赔入口与证据分流 | 按货损位置、面单归属、承运服务和保单选择入口并列证据；期限金额实时核验。 |
| 账单差异与支付状态核对 | 从业务单定位收费行，区分冻结、扣款、付款审核和调账，再核客户合同与实时账单。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
