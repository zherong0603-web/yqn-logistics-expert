# 运去哪操作知识库术语词典

基于 2026-09-29 归档的 99 页资料整理，只说明该资料集中的工作含义，不作为所有物流企业或现行服务条款的通用定义。括号内原文 ID 可在 `../resources/source-register.tsv` 定位。

## 商品与接入

| 术语 | 工作含义与易混点 |
|---|---|
| ERP SKU | YQN 商品建档使用的客户 SKU 编码；不默认等于平台 SellerSKU 或实物条码。（11691） |
| SellerSKU / 产品映射 | 平台 SKU 经店铺产品映射关联到 ERP SKU；一个 ERP SKU 可以对应多个 SellerSKU。（11659） |
| 商品识别码 / 产品标签 | 供仓库扫描识别实物的条码或标签；建了系统 SKU 不代表实物已经可识别。（11691） |
| 最小销售单位 / 原箱内件数 | 前者决定商品规格口径，后者表示每原箱装几件；箱数不能直接当可售件数。（11691） |
| 项目 | 商品与入库计划的业务归类；原文规定一个入库单只对应一个项目，过细分类会影响建单。（11699） |

## 入库与库存

| 术语 | 工作含义与易混点 |
|---|---|
| 入库计划单 | 装箱与发货信息提交仓库审核的单据；草稿、提交、到仓均不自动等于上架可售。（11513） |
| 入库状态 / 审核状态 | “待入库”仍需审核；“已到仓”仅表示至少一箱被确认到仓，须另查上架。（11513） |
| 国际运输方式 / 送仓方式 | 分别描述跨国运输段和目的港/机场至海外仓的送达形式，预约要求随分支变化。（11513） |
| 正常库存 / 不可售库存 | 不可售库存不支持订单出库，但并非已销毁；调拨和库内事务另按原文条件判断。（11660） |
| 可用 / 预留 / 在途 / 总库存 | 可用为正常已上架库存，预留已被占用或保留，在途未上架；原文只说总库存包含可用和预留，未证明严格等式，不能全部当可发货量。（11660） |
| 库存快照 / 变动明细 | 快照看指定时点，变动明细查 SKU 入出库操作；不能用当前总数反推历史原因。（11661、11662） |
| 批次明细 / 库龄报表 | 前者看在库 SKU 的具体天数，后者按天数区间汇总数量。（11663、11664） |

## 出库与运输

| 术语 | 工作含义与易混点 |
|---|---|
| 销售订单 / 发货单 | 上游订单与实际发货执行单据不同；费用和异常查询应核对应使用哪个编号。（11719） |
| 择仓规则 | 在原文限定的 B2C 一件代发范围内优先或排除仓库，不等于保证某仓发货。（11779） |
| 自定义拆单规则 | 针对特定纯大件 B2C 订单，先核不拆条件；不能套用于全部多件或 B2B 订单。（11781） |
| FBA 调拨 / 普通调拨 | 两种 B2B 调拨类型的目的地字段不同；原文注明 FBT 走普通调拨。（11528） |
| 库内订单拦截 | 已提交拦截不等于取消成功；可能成功、失败或部分拦截，需核仓库结果。（11667） |
| LTL / FTL | 零担与整车卡派；资料中的系统询价能力和产品范围为版本化信息。（11509） |
| 卡司 | 卡车承运方；YQN 代理、第三方代理及自营条件不能混作统一服务承诺。（11541） |
| BOL / POD | 卡车提货/自提与送达回传环节的凭证；有 POD 不代表索赔获批。（11509、11782、11536） |
| 面单 / 运单 / Tracking | 标签文件、发运记录和物流追踪号各有用途；有面单不证明已揽收或已结算。（11670、11534、11719） |
| 尾程异动单 / 索赔单 | 前者跟进召回、更址或物流异常，后者按损失/费用原因提交证据；提交任一单据不代表处理成功或获赔。（11701、11638） |

## 退货、索赔与账务

| 术语 | 工作含义与易混点 |
|---|---|
| 退货计划 / 退货认领单 | 可关联来源的退件进入计划；无法识别货主的退件进入认领，快递妥投不等于仓库扫描。（11577、11670） |
| 库内索赔 / 卡司索赔 / 保险理赔 | 责任、申请主体和材料路径不同；保单、合同与承运商实际决定赔付。（11636、11685、11688） |
| 预估结算 / 实际结算 | 打单测算不是最终应收；不同出账模式下实际账单可能补差或替换预估。（11719） |
| 冻结 / 解冻 / 扣款 | 冻结暂时占用可用余额，解冻释放，扣款对应关账后的费用；冻结不是已经支付。（11715） |
| 预充值 / 月结 | 前者先付款并待审核入账，后者按账单和约定账期付款；停发等条件依客户合同。（11716、11717） |
| 问题费用 / 调账 | 提交异议、财务核查与调账到账单是不同阶段；问题金额不自动等于已减免金额。（11783） |

WMS 在归档里出现，但没有被明确界定为一个术语，本词典不补造定义。任何具体费率、索赔期限、禁寄、仓库能力和承运范围均按现行合同/承运商规则核验，详见 `../resources/conflicts.md`。
