# YQN 海外仓物流专家

基于 2026-09-29 保存的 99 页 YQN 海外仓操作知识库，蒸馏出 12 类可路由的业务能力，并为 ChatGPT 项目准备了单文件知识包。此仓库供已有相应资料使用权限的协作者在私有范围内分享，不包含原始登录页面、后台截图、视频、客户资料、收款信息或历史价卡。

## 使用入口

- [GPT_PROJECT_IMPORT.md](GPT_PROJECT_IMPORT.md)：单一 Markdown。把 A 节放进 ChatGPT 项目指令，将整个文件作为项目资料上传；B 节包含独立的业务知识与来源索引。[OpenAI 的项目说明](https://learn.chatgpt.com/docs/projects)指出，项目聊天共享项目指令和上传资料，但 ChatGPT 项目不会自动读取电脑上的文件夹。
- [skill/SKILL.md](skill/SKILL.md)：仓颉编译的 Codex 技能入口，按 12 张能力卡路由。安装到 Codex skills 目录后可用 `$yqn-logistics-expert` 调用。

## 重要边界

- 本仓库**不含 99 页原文**。技能入口保留原作者电脑上的归档路径，仅在那台机器配套原档时经过本地回查验证。其他使用者必须自行取得合法授权的原文并配置自己的来源路径；没有原文或无法登录原站时，不得把能力卡摘要说成已复核的最新规则。
- 页面更新时间不是现行承诺。仓库能力、运价、时效、承运范围、索赔、合同、付款与真实订单状态都要向当前有权系统核实。
- 新媒体内容先做事实卡，再结合真实人物素材做选题或脚本；不得虚构客户案例、人物经历或成效，也不得直接公开内部流程、截图、客户信息和专属价格。
- 这是**私有资料包**，不是公开授权或开源许可；转发访问权前应确认接收者对相关业务资料的使用权限。

## 验证范围

技能包在原作者本机通过格式校验、独立文件完整性审计，以及新 Codex 会话读取本地 11513 原文的运行时探针。单次完整 24 题严格评测经来源纠偏后为 18/24，六个缺项后来分别通过定向回归；这不是同一轮 24/24，也没有登录真实账号执行订单或发布内容。
